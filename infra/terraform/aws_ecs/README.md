# AWS ECS Terraform Skeleton

This folder contains a Terraform skeleton for deploying KubePulse as an AWS ECS/Fargate-style containerized release-validation service.

## Includes

- ECS cluster
- ECS task definition
- CloudWatch log group
- container port mapping
- container health check
- task outputs

## Safe Scope

This is an AWS deployment-readiness artifact, not proof of production AWS operation.
