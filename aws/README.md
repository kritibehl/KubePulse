# AWS Deployment Path

KubePulse includes AWS deployment-readiness artifacts for SRE/cloud/platform workflows.

## Paths

| Target | Purpose |
|---|---|
| ECS | Container service deployment path |
| EKS | Kubernetes/Helm deployment path |
| CloudWatch | Metrics/logs/alerts integration notes |

## Safe Scope

These are deployment-readiness artifacts and notes, not proof of production AWS deployment.
